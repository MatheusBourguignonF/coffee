☕ **Coffee - Manhattan Coffee House**

O **Coffee (Manhattan Coffee House)** é um projeto web desenvolvido com foco na criação de uma landing page para uma cafeteria, explorando conceitos de desenvolvimento front-end moderno, animações e construção de interfaces interativas.

O projeto foi desenvolvido com atenção à experiência do usuário, organização dos componentes, responsividade e efeitos visuais para proporcionar uma navegação agradável e uma identidade visual marcante.

---

## 🚀 Tecnologias utilizadas

Este projeto foi desenvolvido utilizando:

- Next.js
- React
- TypeScript
- Tailwind CSS
- GSAP (GreenSock Animation Platform)
- Lucide React

---

## ☕ Funcionalidades

A aplicação conta com:

- Landing page para cafeteria
- Navegação entre seções da página
- Seção inicial com apresentação da cafeteria
- Cardápio com apresentação dos produtos
- Seção institucional sobre a cafeteria
- Informações de contato e localização
- Horários de funcionamento
- Efeito parallax em imagens de fundo
- Animações de entrada e transições utilizando GSAP e ScrollTrigger
- Animações de textos com SplitText
- Interface responsiva e moderna com Tailwind CSS
